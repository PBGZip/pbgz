口径说明

压缩率（主口径）= 压缩后大小 / 原始数据大小：bam 取 SAM 字节数，fastq.gz/fq.gz 取 FASTQ 字节数；与基准表「压缩率(对原始数据)」同分母，跨工具可比。
差值 pp = 对手压缩率 − pbgz 压缩率（百分点），正值 = pbgz 压得更小。红色= pbgz 更优，绿色= 对手更优。
比对矩阵：bam ↔ cram；fastq.gz / fq.gz ↔ genozip。基准表存在同名数据即对比，不要求往返校验 = OK；无同名数据的样本只汇总 pbgz 自身压缩情况（见「无基线样本」）。
匹配口径：按数据名称精确匹配，仅 .fq.gz / .fq → .fastq.gz 归一；.sorted、_1/_2 不做宽松处理。
速度与内存均与基准表同口径：原始数据 MB / 耗时；maxRSS 峰值内存。速度/内存差别只展示，不触发 WARN。
WARN 触发条件：pbgz 压缩率输给对手基线。FAIL 触发条件：压缩/解压退出码非 0、输出为空、bam 还原大小与原始 SAM 不一致（容差 ±1000 字节）。
fastq 还原只校验退出码与非空，不做大小一致性比对（pbgz 还原 fq 的口径尚未实测确认）。
样本来源：冒烟 = 「冒烟」工作表；标准 = 「数据清单」测试等级=标准；全量 = 「数据清单」测试等级=标准+全量。本轮：「冒烟」工作表（5 个样本，合计 ≈ 2 GB）。
体积上限：不设上限（limits.max_sample_size_gb = 0），所有样本都参跑。
数据生命周期 = 每个样本跑完立即删除 bam 与输出，ref 保留到整轮结束。
