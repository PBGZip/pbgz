说明

压缩率 = 输出大小 / 原始 sam 大小（含 -n 打包的参考序列开销），越低越好。
差值 pp = cram 压缩率 − pbgz 压缩率（百分点）；正值表示 pbgz 更优。
WARN = 软告警，不影响 PASS/FAIL：当前仅在 pbgz 压缩率输给 cram 基线时触发（悬停徽章看原因）。
压缩速度（MB/s）= sam 大小（取自历史表 sam_size 列）/ 压缩墙钟时间；线程数固定，跨 run 可比。
cram 速度基线 = 历史表 cram压缩耗时s / cram解压耗时s 列（用户在同规格 16C 服务器上以 samtools -@ 16 实测），换算分母与 pbgz 相同（sam 大小），可直接比较；单元格为空 = 未测 = 该维度不对比（显示 '—'）。
速度维度只展示、不触发 WARN；压缩率输给 cram 基线仍会 WARN。
解压 MB/s、RSS MB、CPU% 有采集数据时显示，无值以 '-' 占位。
退出码 = 压缩退出码 / 解压退出码；任一非 0 即失败（红色标出），错误日志见下方「失败样本」区（贴日志尾部 30 行）。
未覆盖样本 = 单样本体积超过 limits.max_sample_size_gb（当前 50 GB）的样本，按数据盘规格主动跳过，不计入通过率；要纳入请调大该值并同步放大数据盘。
数据生命周期 = 每个样本跑完立刻删掉它的 bam 与输出（.pbgz / 还原 bam），ref 保留到整轮结束，所以磁盘峰值只装单样本。
解压只校验退出码与输出非空，未做内容一致性比对（可在 ci_config.yaml 打开）。
